# 为什么这个程序不像蚂蚁财富 —— 新手版设计说明

> 目标不是“功能比蚂蚁多”，而是做蚂蚁不会做、也不方便做的部分：**只对用户负责、允许劝退、保留决策证据、数据留在本地**。

## 一、商业平台的三条硬约束

1. **它靠交易和投顾赚钱**：页面希望你多买、快买、买平台推的产品；“现在别买”“这笔不划算”会降低成交。
2. **它只能看到自己平台的数据**：你在别的平台、银行、券商的持仓，它合不进来，真实总成本也算不全。
3. **付费投顾/诊断多是模板化组合**：给的是“一类人”的方案，不是“你这 1000 块、这两笔持仓、这个风险承受力”的方案；而且通常只覆盖平台内产品。

所以，自建工具的价值不是把它的功能抄一遍，而是补它**利益上不愿做、结构上做不到**的事。

## 二、已经做进程序里的差异点

| 差异点 | 商业平台常见做法 | 本程序 v1.5.0 | 状态 |
| --- | --- | --- | --- |
| 敢说“现在别买” | 倾向促成交易，结论模糊 | 买入体检给纪律分；低于 55 分明确“现在不建议买” | 已做 |
| 把回撤翻译成钱 | 只显示百分比 | “先买 100 元，跌 10% 约亏 10 元，你能接受再买” | 已做 |
| 强制冷静期 | 一键下单，最多弹个风险提示 | 想买先写理由，放 24 小时，到期再体检 | 已做 |
| 保留买入理由 | 通常只留交易记录，不留“当时为什么” | 想买清单保存理由；放弃/已买都留痕 | 已做 |
| 真实成本账本 | 平台内收益，费用口径不透明 | 账面盈亏 / 真实盈亏 / 净收益三口径；申购、赎回、管理费拆开 | 已做（v1.1） |
| 买前看你的组合 | 多数只诊断单只基金 | 体检会结合你的单只占比、总投入、已有持仓 | 已做（v1.3） |
| 复盘和今天对比 | 一般只给当日收益 | 昨日 plan vs 今日 plan，标出“仍有效/情况有变” | 已做（v1.4） |
| 账本错账提示 | 平台数据不会错，不会提示你录错 | 0 天却大涨、净值与买入价异常、重复持仓等会提示核对 | 已做（v1.3） |
| 数据私有 | 账号、云端、平台可见 | 本地 SQLite + 本地 Key，不上传 | 已做 |
| 个人投资宪法 | 平台不会替用户执行“单只不超过 30%”的铁律 | 5 条可编辑规则；体检、问一问、组合审计都会拦/提示；已持有的超配不强制卖 | 已做（v1.6） |

## 三、值得继续做、但这一版没做的

| 候选 | 为什么是商业平台弱项 | 难度/风险 |
| --- | --- | --- |
| 跨平台持仓合并 | 平台只看自己的账户 | 需要手动录入/CSV 导入，容易录错；可先做“手动合并” |
| 基金经理变更/规模暴增预警 | 平台有公告，但不会翻译成“对你这笔意味着什么” | 需要额外抓基金经理、规模数据 |
| 真实年化 XIRR | 平台多显示简单收益率，多笔现金流不准 | 纯计算，容易做；适合下一步 |
| 买入后 7 天费率倒计时 | 平台有规则但不主动提醒 | 已有单笔费率优化，可升级为提醒 |
| 持仓相关性/风格重叠 | 需要基金持仓明细，数据源不稳定 | 先用行业/宽基分类做近似，别假装精确 |

## 四、明确不做的事

- 不做全市场基金排行、社区、直播、带货：个人自用不需要，只会增加噪音。
- 不接自动交易、不保存券商密码：一旦碰钱，安全边界完全不同。
- 不假装能预测涨跌：所有结论只解释趋势、回撤、费率、仓位和用户自己的纪律线。

## 五、新手怎么用（最短路径）

1. 先录 1-2 笔真实持仓（日期、金额、净值别填错）。
2. 看「今天怎么办」：今天要不要动、跌破哪条线再动。
3. 想买新基金：先「买前体检」，看纪律分和“亏多少钱”。
4. 想买大额前，先在「我的投资宪法」里按金额核对；不通过就先放 24 小时，别硬上。
5. 还是想买：点「先放 24 小时」，写一句理由；明天再看还成不成立。
6. 每周看一次「复盘」和「深度分析」，别每天盯盘。
