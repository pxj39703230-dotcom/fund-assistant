# 基金投资助手 v1.6.0

个人自用的基金持仓助手：本机跑一个 Node 服务，浏览器打开就能看组合、算真实收益、**按纪律给出"今天该不该动"的结论**、买之前先体检、拿不准还能直接问它、收每日复盘。数据全部存在本地 SQLite（`fund.db`），不联网上传。

> 它不是行情预测工具，也不替你下单。它做的是把"趋势、回撤、费率、你自己设的纪律线"翻译成一句能执行的话：**今天动不动、动多少、跌破哪条线再动**；买新基金前，先用同一套纪律给它打个分。

## 一、先把口径说清楚（这是整个程序的地基）

| 口径 | 怎么算 | 界面位置 | 容易踩的坑 |
| --- | --- | --- | --- |
| 账面盈亏 | 市值 − 买入金额 | 持仓卡片第三行 | 只反映净值涨跌，没算申购费 |
| 真实盈亏 | 市值 − 买入金额（申购费已在份额里内扣） | 持仓卡片 + 指标卡 | **管理费、托管费已含在公布净值里，不能再扣一次** |
| 净收益（现在赎回） | 市值 − 赎回费（按持有天数阶梯费率） | 持仓卡片 + 指标卡 | 赎回费随持有天数变化，今天和明天不一样 |

三个关键规则：

1. **申购费内扣**：`确认份额 = 买入金额 ÷ (1 + 申购费率) ÷ 买入净值`，申购费 = 买入金额 − 买入金额 ÷ (1 + 申购费率)。不是"份额 = 金额 ÷ 净值"再另扣钱。
2. **管理费/托管费不参与计算**：股票基金净值是**已扣除**管理费、托管费后的数值，程序只把它们展示出来，重复扣会把收益算低约 1.4%/年。
3. **赎回费阶梯按当前持有天数取档**，净收益按"此刻全部赎回"估算；持有天数按自然日计算，实际以基金确认日为准确。

## 三、看盘与决策：程序每天替你回答三个问题

### 1）今天要不要动手？

页面最上方的「今天怎么办」面板就是答案，只有三种话：

| 结论 | 含义 | 你要做什么 |
| --- | --- | --- |
| 今天有 N 笔需要处理 | 有仓位触发了纪律线（止损、止盈、波段破位） | 看下面的动作卡，逐笔处理 |
| 今天不用动手，有 N 件事提前知道 | 没到操作点，但有集中度、大盘大跌、净值没更新等提示 | 知道就行，不用操作 |
| 今天什么都不用做 | 所有仓位都在纪律线内 | 关掉页面 |

没有动作时，面板会列出每笔持仓的"接下来盯的线"（跌破就减仓价、20 日均线），你不用自己算。

### 2）这笔该抛还是该拿？

每张持仓卡中间多了一块结论区：**策略（长线/波段）+ 结论 + 具体动作 + 触发价**，下面可展开"为什么这么判断"（趋势、位置、费率、纪律线四条证据）。

### 3）长线还是短线？

程序按基金类型自动判断，也可以手动改（添加/编辑持仓时选「持有策略」）：

| 策略 | 判断依据 | 怎么对待 |
| --- | --- | --- |
| 长线 | 债券/货币/指数/ETF/沪深300/中证/纳斯达克/标普/MSCI/宽基 | 按年拿，只在止损、止盈、极端回撤时动 |
| 波段 | 消费/白酒/医药/军工/新能源/半导体/科技/券商/地产/有色/煤炭/港股/黄金等行业主题；或年化波动 ≥ 22% | 跌破 20 日均线就减，趋势转弱就走 |

### 4）判断规则（按优先级，先命中先执行）

| 优先级 | 条件 | 结论 | 动作 |
| --- | --- | --- | --- |
| 1 | 拿不到净值 | 观察 | 先同步净值 |
| 2 | 历史净值 < 12 个交易日 | 观察 | 样本不够，不下结论 |
| 3 | 真实亏损 ≥ 止损线 | 止损离场 | 今天先卖一半，剩下一半明天卖；若等几天降费能省 ≥ 市值 0.4%，则提示等 |
| 4 | 刚买入 < 7 天且赎回费 ≥ 1% | 先别动 | 白交 1.5% 手续费不划算，到第 7 天再看 |
| 5 | 真实盈利 ≥ 止盈线 | 止盈 | 长线且趋势强 → 卖一半、止盈线上调 10%；否则分批止盈 |
| 6 | 波段仓位趋势转弱（趋势分 ≤ −1） | 减仓 / 先降风险 | 跌破 20 日线减一半；已跌破 50 日线则止损上移到现价 −3% |
| 7 | 从买入后高点回撤 ≥ 12% 且趋势没坏 | 减仓 | 先减 1/3 锁利润 |
| 8 | 长线浮亏但趋势没坏 | 持有 | 不动，等趋势或止损说话 |
| 9 | 其他 | 持有 | 不动 |

**组合级提示**：大盘单日跌超 1.5%（系统性下跌别恐慌割）、单笔占比 ≥ 40%（且 ≥ 3 笔）、同一主题合计 ≥ 50%、有净值没更新、组合整体浮亏 ≥ 5%。

> 以上全部是规则计算，**不预测涨跌、不构成投资建议**；最终买卖与盈亏由你自己承担。页面底部也写了同样的免责说明。

## 四、买之前先体检，拿不准就问

### 1）买前体检（专治"怕盲目买亏"）

在「添加持仓」里填 6 位基金代码，点 **买前体检**（不用先填金额、日期）。程序拉 90 个交易日净值，按同一套纪律算四件事，再给一个 0-100 的**纪律分**：

| 看什么 | 怎么算 | 为什么对小白重要 |
| --- | --- | --- |
| 趋势 | 近 20 日涨跌、是否站上 20/50 日均线 | 下跌趋势里接飞刀，是新手最常见的亏法 |
| 位置 | 距近一年高点回撤多少 | 刚跌 3% 叫追高，跌 20% 才叫便宜 |
| 波动 | 近 60 日年化波动 | 波动 30% 的基金，跌 15% 是常态，别按存款心态买 |
| 成本 | 申购费、最短档赎回费 | 7 天内赎回常收 1.5%，买错一次光手续费就够疼 |

打分规则（`backend/domain/fundCheck.js` 顶部的 `RULES`，可自己改）：

| 项 | 加减分 |
| --- | --- |
| 基准 | 60 |
| 趋势分 ≥ 2 / = 1 / ≤ −1 | +12 / +5 / −12 |
| 距高点 ≤ −20% / ≤ −12% / > −3% | +4 / −4 / −6（追高） |
| 年化波动 ≥ 28% / ≥ 22% | −10 / −5 |
| 波段型且趋势转弱 | −8 |

结论只有四种：**可以分批买（≥72）/ 先小仓位试（55-71）/ 现在不建议买（<55）/ 数据不够（样本 < 12）**。同时给执行计划：首笔金额（组合的 5%，100-1000 元封顶）、分 3 批、止损 10-15%、止盈 20-30%、7 天内先别卖。组合里某只已占 40% 以上会被点名，避免越买越集中。

### 2）问一问（把结论翻译成人话）

右下角悬浮按钮「问一问」，也可以直接问快捷问题：

| 你问 | 它答 |
| --- | --- |
| `110022 能不能买` | 先体检，再给结论 + 纪律分 + 体检卡（依据、风险、怎么买） |
| `现在该卖吗` | 逐笔给"拿/减/卖"、触发价、要盯的线 |
| `我的仓位有问题吗` | 集中度、浮亏、净值过期等组合级风险 |
| `今天大盘怎么样` | 三大指数、交易状态、盘中估值有没有 |
| `赎回费怎么算` | 当前档位、再等几天降档、能省多少 |
| 只说"我想买基金" | 不瞎猜，先要 6 位代码 |

**两种回答模式**：没配 Key 时走**本地规则**（永远可用，答案里的数字都来自你的真实持仓）；在页面「AI 设置」里选供应商、填 Key 并保存后自动改走大模型（也兼容 `.env`），模型只负责把同一份数据说清楚，失败会**自动回退规则**并在气泡下标注来源。随时可以换豆包 / DeepSeek / OpenAI / 通义，保存后下一句提问就生效。无论哪种，都**不预测涨跌**。

### 3）手机端：能当 App 用（PWA）

- 手机和电脑连同一个 Wi-Fi，浏览器打开 `http://<电脑IP>:3000`。
- Chrome / Edge：菜单里「添加到主屏幕 / 安装应用」，之后从桌面图标进，**没有地址栏**，和 App 一样全屏。
- iPhone：Safari → 分享 → 「添加到主屏幕」，图标与启动图已配好。
- 已做：`manifest.json`、192/512 图标、iOS `apple-touch-icon`、`theme-color`、底部安全区适配；用 Chrome 的 `Page.getInstallabilityErrors` 实测**无安装错误**。
- 没做 Service Worker：这是本机服务，离线打不开本来就不可用，加缓存只会让你改了页面却看到旧版。

### 4）实时性到什么程度

| 时段 | 刷新 | 能看到什么 |
| --- | --- | --- |
| 交易时段（9:30-15:00） | 指数 30 秒 | 指数实时点位；基金卡片显示东财盘中估值 `GSZ`，标"盘中估算" |
| 盘前 / 盘后 / 周末 | 最多 5 分钟一次 | 最新公布净值（净值本身每天只更新一次） |

基金没有股票那种逐笔行情：盘中估值是第三方按持仓估算的，**官方净值要等晚上更新**，所以程序不会假装它是实时净值。

## 六、功能

| 功能 | 说明 |
| --- | --- |
| 今日决策 | 「今天怎么办」：三态结论 + 待办动作卡（含金额与价位）+ 组合风险提示；无动作时列出各持仓"盯着哪条线" |
| 持仓结论 | 每笔给策略、结论、具体动作、触发价（跌破就减仓 / 涨到就止盈 / 20 日均线），可展开四条判断依据 |
| 买前体检 | 输入代码即可打分（0-100）+ 结论 + 首笔金额/分批/止损止盈，买之前先过一遍纪律 |
| 问一问 | 悬浮问答：买不买、卖不卖、仓位、大盘、费率；规则回答永远可用，配 Key 可接大模型，失败自动回退 |
| 看盘条 | 顶部上证 / 深证 / 创业板实时点位与涨跌幅，交易时段 30 秒刷新；盘中若有估值，卡片上显示"盘中估算" |
| 策略设置 | 自动判断 / 长线 / 波段，可按持仓手动覆盖 |
| 组合总览 | 累计投入、当前市值、真实盈亏、净收益、今日盈亏、持仓笔数 6 张卡 + 持仓分布条 |
| 持仓管理 | 添加 / 编辑（止盈止损、策略、备注）/ 删除；代码输入 6 位自动带出名称、净值、费率 |
| 盈亏明细 | 每笔三口径盈亏、持有天数、份额、净值日、当日涨跌、止盈止损进度 |
| 赎回建议 | 按当前档位算费率，提示"再持有 N 天降到 X%，约省 Y 元"，并判断值不值得等 |
| 费用明细 | 可折叠：申购费、赎回费率与金额、管理费/托管费（标注"已含在净值中"） |
| 自动拉净值 | 交易日 18:00 / 20:00 / 22:00 三次；非交易日跳过；启动时若当天没数据会自动补跑 |
| 自动复盘 | 每日 22:30、周日 20:00 周复盘、月末 20:30 月复盘；日复盘含概况、涨跌榜、持仓明细、操作建议、**持仓决策** |
| 提醒 | 止盈/止损触线（含"今天该卖一半"的动作提醒）、净值缺失、净值过期、集中度、回撤，写入 `alerts` 表并在页面提示 |
| 数据容错 | 三级数据源 + 缓存 + 陈旧数据标记 + 失败降级 |
| 响应式 | 1024 / 720 / 420 三档断点；手机端底部弹层问答、按钮 ≥ 40px、表单两列 |
| PWA | 可添加到主屏幕，独立窗口全屏运行，桌面图标 192/512 |

## 十二、备份与回滚

**日常备份**：每天 23:10 自动备份到 `backups/fund-YYYY-MM-DD-HH-mm-ss.db`（Asia/Shanghai 本地时间），也可随时 `npm run backup`。

**恢复**：

```powershell
# 1. 停服务（Ctrl+C）
# 2. 先给自己留一份当前库
Copy-Item fund.db "backups\manual-$(Get-Date -Format yyyyMMdd-HHmmss).db"

Remove-Item fund.db-wal, fund.db-shm -Force -ErrorAction SilentlyContinue
# 5. 重启 npm start
```

**整体回滚到重构前**：`backups\20261113-054207-before-refactor\` 是重构前的完整快照（14 个文件），把它覆盖回项目根、`npm install`、`npm start` 即可。新库多了表与列，旧程序按原表读写不受影响。

## 十四、已知限制

- **决策与体检都是规则，不是预测**：只回答"纪律线到了没有""这个位置买划不划算"，不判断未来涨跌；所有结论都可能错。
- **休市日历只做到 2026 年**，2027 年需在 `backend/config/market-holidays.json` 追加，否则只按周末判断。
- 盘中估值只在交易时段可用（东财 `GSZ` 为空时退回最新净值），非交易时段卡片不会显示"盘中估算"。
- 持有天数按自然日，不区分申购确认日 T+1；赎回费档位是近似口径，最终以基金公司为准。
- 分红、拆分未单独建模（净值本身已反映），现金分红到账不会自动记为收益。
- SQLite 单进程：不要同时开两个 `npm start` 指向同一个 `fund.db`。
- 上游接口是公开页面，随时可能改版；改版后需更新 `fundDataService.js` / `marketService.js` 的解析。
- 只跟踪"买入金额 + 份额"，不支持真正的定投计划（不会自动扣款/自动记账）；「定投测算」只是按历史净值回测，卖出部分份额仍要手工新增/删除持仓。
- 体检是**买前筛查**，不是收益预测；分数只是规则加权，趋势一变结论就变。
- 大模型问答需要自己配 Key；**未配 Key 时只有规则回答**。页面可随时切换 AI，保存后立即生效；真实模型的成功链路仍需你填自己的 Key 后跑一次（本轮已实测保存、切换、清除与失败回退）。
- 复盘联动只对**新格式复盘**生效（`data.plan` 从 v1.4.0 开始保存）；更早的历史复盘没有结构化结论，不会自动出现在对比卡里。
- `frontend/app.js` 是重构前遗留的旧脚本，已不被引用，可自行删除。
- PWA 安装入口依赖浏览器菜单；部分国产浏览器不提供"安装"，用 Chrome / Edge / Safari 即可。

### 4. 复盘 → 今日建议的联动

- 每天生成日复盘时，把当日结构化结论 `plan{headline,tone,actions,flags}` 一并存进 `reviews.data`。

  - `仍有效`：结论没变，继续按它执行；
  - `情况有变`：某只基金从"该卖"变"持有"（或反过来）、新出现操作、移出操作区；

- 加入时必须/建议写一句“为什么想买”，存进本地数据库；24 小时内显示倒计时，到期后变成“到期可决定”。
- 到期后可以「去体检」「我买了，去记账」或「不买了」；放弃/已买都会保留记录，作为决策留痕。
- 这是反商业动机的设计：蚂蚁财富希望你立刻下单，它不会拦你；这个程序只对你负责。
- 冷静期是**提醒和留痕**，不是强制锁单；你仍然可以自己去别的平台买，但至少有一次停下来的机会。

接口：

```text
GET    /api/watchlist            当前冷静中/到期的清单
POST   /api/watchlist            加入（code、targetNav、reason）
PATCH  /api/watchlist/:id        标记 ready / bought / dropped
DELETE /api/watchlist/:id        删除（一般用 PATCH 保留记录）
```

### 3. 把百分比翻译成“我会亏多少钱”

体检卡新增一行：

> 先买 100 元，若触发 -10% 止损，约亏 10 元。这个数能接受，再决定买。

新手对“回撤 20%”没感觉，对“亏 10 元”有感觉；这是商业平台不会强调的“劝退信息”。

### 5. 这一版仍然不做什么

- 冷静期到期不会弹系统通知；需要打开页面看（后续可加浏览器通知）。

## 十八、v1.6.0 新增：投资宪法（下单前先过你自己的规则）

这一版不再加“看数据”的页面，而是把新手最容易犯的错变成**买前会真的拦一下**的规则。规则由你自己设，存在本地 `settings` 表，不新增表、不上传。

### 1. 五条默认规则

| 规则 | 默认值 | 它防的是什么 |
| --- | --- | --- |
| 单只最多占比 | 30% | 一只基金决定全部盈亏 |
| 单笔最多亏 | 50 元 | 把“止损 -10%”翻译成“这笔最多亏多少钱” |
| 新基金首笔最多 | 300 元 | 第一次就买满，跌了拿不住 |
| 体检分至少 | 55 分 | 低于“能买但先小仓位”的线就不买 |
| 最多持有几只 | 5 只 | 为了分散买一堆，最后看不过来 |

两个刻意保留的例外：

- **第一只基金不按 30% 卡**：组合只有 1 只时占比必然接近 100%，否则新手永远买不了第一笔；仍受“首笔 ≤300 元”和体检分约束。
- **已持有的超配不强制卖**：只提示“先别加仓，下一笔换方向”，不制造“必须割肉”的焦虑。

### 2. 在哪里拦

- **买前体检**：体检请求会带上金额（默认按计划首笔 100 元），调用宪法逐条核对。不通过时：
  - 卡片头 chip 从“能买，但先小仓位”改为“宪法不通过”；
  - 隐藏“怎么买”计划和“先买 100 元约亏 10 元”，避免一边说别买、一边教怎么买；
  - 保留“先放 24 小时（宪法未过）”按钮，让你冷静而不是直接下单。
- **问一问**：问“110022 买 500 元行不行”时，会从问题里读出 500 元，而不是拿默认 100 元糊弄；宪法不通过时第一句就是“按你的投资宪法，这笔先别买”。
- **独立核对**：首页「我的投资宪法」面板里可直接输入代码 + 金额核对一笔，不写持仓也能试算。
- **组合审计**：`GET /api/portfolio` 的 `constitution.audit` 会指出当前组合的单只占比、只数、首只基金问题；首页无需再单独请求。

### 3. 编辑与接口

面板右上角「改规则」可改启用开关和 5 个数字；保存后立即重新拉组合，审计同步刷新。

```text
GET  /api/constitution              读规则（不含 audit）
PUT  /api/constitution              保存规则
POST /api/constitution/check        核对一笔 { code, amount, mode? }
GET  /api/funds/:code/check?amount= 体检并带宪法结果
```

规则对象：

```json
{
  "enabled": true,
  "maxSingleWeight": 30,
  "maxLossPerBuy": 50,
  "maxFirstBuy": 300,
  "minCheckScore": 55,
  "maxFunds": 5
}
```

### 5. 边界

- 宪法是**提醒和拦截展示**，不会硬锁“添加持仓”按钮，也不会阻止你去别的平台下单；最终仍由你决定。
- AI 的 system prompt 和 `fund-coach` Skill 都写了“不得建议绕过宪法”；但当前未配置真实 Key，AI 成功链路仍未实测。
- 宪法只存本地；换电脑/重装前先备份 `fund.db`。
