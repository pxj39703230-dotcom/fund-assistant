# 📈 基金投资助手

个人基金投资管理系统，专注于精准盈亏计算、智能决策建议和自动复盘。

---

## ✨ 核心功能

### 1. 精准盈亏计算
- ✅ 扣除申购费（1折优惠）
- ✅ 扣除管理费（按日计提）
- ✅ 扣除托管费（按日计提）
- ✅ 扣除赎回费（根据持有天数阶梯计算）
- ✅ 显示账面盈亏、真实盈亏、净收益三种口径

### 2. 智能提醒
- ⚡ 单日涨跌超过3%提醒
- 🎯 触达止盈线提醒
- 🛑 触达止损线提醒
- 💡 赎回费优化建议（如：再持有X天可节省X元）

### 3. 自动化运行
- 📥 每个交易日自动拉取净值（15:30/18:00/20:00/22:00）
- 📊 每天22:30自动生成复盘报告
- 📅 周末自动生成周度复盘
- 📅 月末自动生成月度复盘

### 4. 数据安全
- 💾 本地SQLite数据库，数据完全在你掌控中
- 🔒 无需联网注册，无需上传个人信息
- 📦 支持数据备份
